# Storytelling & Copywriting Framework

The narrative structure is critical for making design portfolios compelling and memorable. This section provides storytelling frameworks, copywriting guidelines, and content templates for effective storytelling.

## Narrative Framework

### The 3-Act Structure for Design Case Studies

| Act | Description | Portfolio Element |
|-----|-------------|-------------------|
| **Act 1: Problem** | Identify the user's challenge | Problem statement, user research findings |
| **Act 2: Solution** | Show your approach and execution | Process, wireframes, design decisions |
| **Act 3: Impact** | Demonstrate the results | Metrics, testimonials, final outcomes |

### Storytelling Template

```markdown
## [Project Name] Case Study

### Problem
[Brief description of user problem or business challenge - 1-2 sentences]

### Solution
[Your approach, tools used, and key design decisions]

### Impact & Results
- [Metric 1]: [Value] (e.g., "30% increase in conversion rate")
- [Metric 2]: [Value] (e.g., "40% reduction in task completion time")
- [Qualitative Result]: [Description]

### Key Takeaways
- [Insight 1]
- [Insight 2]
- [Insight 3]
