# Branding Guidelines

Establishing a strong visual and verbal brand identity is essential for professional portfolio presentation. This section provides comprehensive branding guidelines for portfolio projects.

## Brand Architecture

### Brand Levels

| Level | Description | Portfolio Application |
|-------|-------------|----------------------|
| **Brand Identity** | Core identity, values, personality | Portfolio tone, visual style |
| **Brand Messaging** | Value proposition, positioning | Project summaries, case studies |
| **Brand Experience** | How the brand is experienced | Portfolio interactions, navigation |
| **Brand Extensions** | Applications across touchpoints | Social media, resume, presentation |

## Visual Brand Elements

### Logo Design Guidelines

```markdown
### Logo Specifications

**Primary Logo**
- Format: SVG (vector) + PNG (web)
- Clear space: Equal to logo height on all sides
- Minimum size: 44px for web, 1 inch for print
- Color: Primary palette (do not invert)
- Background: Transparent or white

**Logo Variations**
1. Full (Icon + Text) - Primary use
2. Icon Only - Favicon, social avatars
3. Text Stacked - Vertical layouts
4. Monochrome - Single color applications
```

## Verbal Brand Identity

### Brand Voice Attributes

| Attribute | Description | Example |
|-----------|-------------|---------|
| **Professional** | Competent, experienced | "Senior Product Designer with 8+ years experience" |
| **Human-centered** | Empathetic, user-focused | "Designing for real user needs" |
| **Thoughtful** | Strategic, well-reasoned | "Data-informed design decisions" |
| **Modern** | Contemporary, innovative | "Cutting-edge digital experiences" |

### Tone by Context

| Context | Tone | Example |
|---------|------|---------|
| Headlines | Confident | "Redesigning the Future of Sustainability" |
| Body Copy | Informative | "The project involved a complete overhaul of..." |
| CTAs | Action-oriented | "View the Full Case Study →" |
| Social | Conversational | "Excited to share this project!" |

## Brand Application Guide

### Portfolio Sections

**Hero Section**
- Strong headline (12 words max)
- Clear value proposition (15 words max)
- Visible CTAs (2 primary actions)

**Project Cards**
- Project name + year
- 1-line problem statement
- Key technologies/methodologies
- Hover state reveals full description

**Case Studies**
- Problem → Solution → Impact structure
- Before/after comparisons
- Process diagrams
- Metrics with visualizations

### Brand Elements Across Platforms

```markdown
=== Portfolio Website ===
Logo: Full icon + text (top-left)
Navigation: Clean, minimal
Color: Primary brand, expanded palette for sections

=== Social Media ===
Logo: Icon only (for profile pics)
Style: Consistent with website
Bio: Professional summary + keywords

=== Resume/CV ===
Typography: Same font family
Colors: Black/Deep gray only
Layout: Clear hierarchy matching portfolio
```
